01 / ABOUT

Background & Perspectives

A straightforward summary of my academic path, technical curiosity, and how I approach writing software.

I am a Master's student in Information Technology who values clear fundamentals, thoughtful system design, and pragmatic problem solving.

My path in computing began with core programming in C and C++. Working close to memory, pointers, and data structures taught me discipline and respect for how machines operate under the surface. Rather than viewing code through abstractions alone, I learned to think about performance, state, and reliability early on.

From there, I expanded into object-oriented engineering with Java and native Android development. I enjoy structuring mobile applications where lifecycle management, responsive interfaces, and local persistence work cohesively. On the server side, I build modular services using Python (Flask, FastAPI) and Node.js, backed by relational SQL schemas.

Currently in my second year of M.Sc. IT at Deogiri College, I spend my time exploring backend paradigms, database design, and mobile architectures. I prefer straightforward code that is easy for humans to reason about and dependable when deployed.
